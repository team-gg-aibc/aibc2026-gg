# 현장 상황판 사이트맵

> 이 파일이 화면 목록의 원본이다(11-06 PM vault에서 옮김, 내용은 11-01 판 그대로).

> 코드: `U-` 휴대폰 쪽 화면(시민 · 현장 직원) · `A-` 상황판 화면(6종 조례 담당 부서 공무원) · `UI-` 페이지 안 부품(그 페이지 바로 아래) · `C-` 여러 화면 공통 모듈(맨 아래 따로)
> 우선순위: 1순위 = 데모 · 발표에 나오는 주요 화면 · 2순위 = 1순위를 잇거나 모양이 다른 화면 · 나중 = 흔하거나 다른 화면과 비슷한 화면
> **1순위는 발표 화면 하나다: 오른쪽 A-01 현장 상황판 + 왼쪽 휴대폰 틀(첫 장면 U-02 시민 신고, 마지막 장면 U-01 현장 휴대폰). 만들 순서는 A-01 먼저.**
> 채점 API(F1 · F2)는 화면이 아니라 여기 넣지 않았다. 로그인 · 회원가입은 Won't라 뺐다.
> 10-31 회의와 회의 뒤 결정(부서 자동 배정 · 시민 신고 화면 · 6종 밖은 시연에 안 보임)으로 고쳤다. 이유는 [PRD](PRD.md) 기록 10-31 줄에 있다.
