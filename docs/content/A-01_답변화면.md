> [!note] 읽는 규칙 · 화면에는 보이지 않습니다 (3판 화면 파일 공통: A-01_답변화면 · C-01_답변초안카드 · U-02_시민문의)
> - `#` 화면 제목. 파일 하나에 하나.
> - `#`이나 `##` 바로 아래 `>` 한 줄: 그 화면이나 구역에서 가장 먼저 읽을 문장. `#` 아래 문장이 화면에서 가장 무겁다.
> - `##` 화면 안의 구역. 위에서 아래로 이 순서대로 놓는다.
> - 기호 없는 문장: 그 구역의 보통 안내 문장.
> - `-` 목록: 같은 무게의 항목. 같은 모양으로 나란히 놓는다.
> - 표 머리가 `상황 | 보일 말`: 평소에는 보이지 않고 그 상황이 되면 보일 문장. 이 표가 든 `## 상황별 안내`는 파일 맨 끝에 두고 구역으로 놓지 않는다.
> - 표 머리가 `항목 | 내용`: 이름표와 값이 한 줄씩 짝을 이룬 묶음. `·` 앞은 배지, 뒤는 배지 옆 짧은 설명. `—`는 비어 있음.
> - `- 칩:` 켜고 끄는 필터, `·`로 칩을 나눈다. `- 버튼:` 누르는 버튼. `- 입력:` 글을 넣는 칸, `·` 뒤는 칸 안의 흐린 예시.
> - `- 보기:` 한 묶음에서 하나만 고르는 버튼, `·`로 고를 것을 나눈다. 처음엔 첫째가 골라져 있다. `- 고르기:` 목록에서 하나를 고르는 칸, `·` 뒤는 처음 보이는 글과 고를 것들.
> - `*기울임*` 한 줄: 작은 보조 문구.
> - `> [!note]`: 화면에 보이지 않는 메모.
> - 이 프로젝트: 표 머리가 `들어온 문의 | …`면 문의 목록이자 지도 위 점 목록(가상 예시). 표 머리가 `상태 | 보일 말` · `출처 | 보일 말`이면 꼬리표 이름(색만으로 가르지 않고 이 글자를 늘 함께 보인다). 표 머리가 `조례 | …`면 화면이 쓰는 자료 표.

> [!note] 3판(PRD 11-11 「문의 답변 창구」)에 맞춰 새로 쓴 안이다. 앞 판의 [A-01 현장 상황판](A-01_상황판.md) · [A-04 한강 3D 지도](A-04_한강지도.md)를 이 한 화면으로 합쳤다(낮 지도 위에 문의 목록과 답변 초안 카드). 앞 판 파일은 앞 판 시연 화면(`demo/hangang-3d`)이 쓰므로 그대로 둔다. 사이트맵(`docs/sitemap.md`)은 아직 앞 판이라 코드 · 이름이 다르다 — [확인 필요] 사이트맵 3판 반영(만들 것 목록 D3). 이 화면은 `demo/desk`가 읽는다.

# 문의 답변 창구

> 시민 문의에 서울시 조례 근거 조항을 붙인 답변 초안을 만들어 드립니다. 초안은 담당자가 확인하고 승인해야 시민에게 나갑니다.

## 기준

- 서울시 조례 6종 · 2026-10-01 시행본 기준
- 시연 화면 · 여러 담당자에게 간 문의를 한 화면에 모아 보였습니다. 건수는 실제 통계가 아닙니다
- 가상 문의 출처 · NVIDIA Nemotron-Personas-Korea(CC BY 4.0)를 바탕으로 만들었습니다

> [!note] PRD 3절 화면: 「2026-10-01 시행본 기준」, 문의 출처(가상 · 공개 게시판), 가상 문의 출처를 늘 보인다. 건수(부서 칩의 숫자)는 실제 통계가 아니라 화면을 보이려고 정한 값이라고 밝힌다. 기관 로고 · 공식 시스템 이름을 화면 이름으로 쓰지 않는다(그래서 「문의 답변 창구」). 담당자 화면이 여러 담당자의 문의를 모은 것이라는 줄은 PRD 2절.

## 들어온 문의

> 번호는 들어온 순서입니다. 문의를 누르면 답변 초안이 열립니다.

- 보기: 전체 · 승인 전 · 승인 완료
- 칩: 모든 소관 부서 · 주차계획과 · 정원도시정책과 · 동물보호과 · 자전거PM과 · 청년정책담당관 · 건강관리과 · 근거 조항 없음
- 버튼: 시연 문의 들여오기
- 버튼: 처음 상태로 되돌리기

*시연 문의는 엔진에 미리 넣어 받아 둔 답으로 보입니다. 시민 화면에서 보낸 문의는 엔진이 그때 초안을 만듭니다.*

> [!note] 「부서별 보기」(PRD F5): 칩은 인용한 조례의 소관 부서 여섯 곳. 조항을 붙이지 못한 문의는 「근거 조항 없음」에 모인다. 「승인 전 · 승인 완료」는 F3의 「승인 전 · 후 나눠 보기」. 「처음 상태로 되돌리기」는 영상을 여러 번 찍으려는 시연용 버튼(만들 것 목록 S6)이다.

| 들어온 문의 | 출처 | 상태 | 소관 부서 |
|---|---|---|---|
| 1 · 공영주차장에서 2시간 요금을 미리 냈는데, 안 쓴 한 시간 요금은 환불되나요? | 시민 화면에서 보냄 | 승인 전 · 답변 초안 | 주차계획과 |
| 2 · 지하철역 옆 공영주차장에 세우고 지하철로 갈아타면 할인된다던데, 환승한 건 어떻게 확인받아요? | 가상 문의 | 승인 전 · 답변 초안 | 주차계획과 |
| 3 · 우리 집 대문 앞에 모르는 차가 이틀째 서 있어서 제 차를 못 빼요. 견인해 달라고 할 수 있나요? | 가상 문의 | 조항을 찾지 못함 · 담당자 확인 | — |

> [!note] 가상 예시: 위 줄은 모양을 보이려는 예시다. 화면은 서버가 준 문의로 목록을 그린다. 출처 낱말은 셋이다: 「시민 화면에서 보냄」 · 「가상 문의」 · 「공개 게시판 글(요지)」.

| 상태 | 보일 말 |
|---|---|
| 만드는 중 | 초안 작성 중 |
| 초안 | 승인 전 · 답변 초안 |
| 승인 | 승인 완료 · 시민에게 보냄 |
| 6종 밖 | 6종 밖 · 초안 없음 |
| 못 찾음 | 조항을 찾지 못함 · 담당자 확인 |
| 실패 | 불러오지 못함 · 다시 시도 |

| 출처 | 보일 말 |
|---|---|
| 시민 | 시민 화면에서 보냄 |
| 가상 | 가상 문의 |
| 공개 | 공개 게시판 글(요지) |

> [!note] 셋으로 나누기(PRD 3절 화면, 동규 11-11): 엔진의 「확인 불가」를 곧바로 「6종 밖」이라 부르지 않는다. 「6종 밖」은 엔진이 6종이 다루지 않는 조례 · 관할이라고 가른 것만, 그 밖의 확인 불가는 「조항을 찾지 못함」, 시간 초과 · 오류 · 연결 실패는 「불러오지 못함」.

## 지도

- 문의 장소 · 지도 점의 숫자는 들어온 순서입니다
- 장소 표시 · 시연용으로 놓은 대략 위치입니다
- 급지 · 확인 필요
- 공원 구분 · 확인 필요
- 장소 확인 필요 · 문의에 장소가 없습니다

> [!note] 화면에서는 시민 화면 · 카드 · 지도 안내 모두 「장소」 한 낱말로 쓴다(PRD의 「자리」와 같은 뜻. 한 카드에 「자리」와 「장소」가 섞이지 않게). PRD F10(자리 속성)은 첫 판에서 장소 이름과 대략 위치까지만 보인다. 급지 · 공원 구분 자료는 아직 없다(만들 것 목록 M1, PRD 미정 9). 그 자리에서 쓴 문의의 장소는 PRD 미정 13 — 이 첫 판은 시민 화면에서 장소를 고르게 하고, 고르지 않으면 「장소 확인 필요」로 보인다(추천안, 동규 확인 전).

## 상황별 안내

| 상황 | 보일 말 |
|---|---|
| 불러오는 중 | 문의 목록을 불러오고 있습니다. |
| 들어온 문의 없음 | 아직 들어온 문의가 없습니다. 시민 화면에서 문의를 보내거나 「시연 문의 들여오기」를 눌러 주세요. |
| 불러오지 못함 | 문의 목록을 불러오지 못했습니다. 화면 서버가 켜져 있는지 확인한 뒤 다시 시도해 주세요. |
| 「승인 전」으로 거른 결과 없음 | 승인을 기다리는 문의가 없습니다. |
| 「승인 완료」로 거른 결과 없음 | 아직 승인한 답이 없습니다. |
| 고른 소관 부서의 문의 없음 | 이 소관 부서로 묶인 문의가 없습니다. 「모든 소관 부서」를 눌러 주세요. |
| 엔진에 연결됨 | 엔진 연결됨 · 새 문의는 엔진이 그때 초안을 만듭니다 |
| 엔진 기록 없이 연결됨 | 엔진 연결됨(답 네 칸만) · 판정은 보이지 않고, 원문 구절 대신 조항 원문을 보입니다 |
| 엔진에 연결되지 않음 | 엔진에 연결되지 않음 · 새 문의는 「불러오지 못함」으로 보입니다 |
| 미리 받은 답으로 보임 | 미리 받은 답으로 보이는 중 · 엔진을 부르지 않습니다 |
| 시연 문의를 들여오는 중 | 시연 문의를 차례로 들여오고 있습니다. |
| 시연 문의를 다 들여옴 | 시연 문의를 모두 들여왔습니다. |
| 처음 상태로 되돌리기 확인 | 들어온 문의와 승인 기록을 모두 지우고 처음 상태로 되돌립니다. 되돌린 뒤에는 다시 살릴 수 없습니다. |
| 화면 문구 파일을 읽지 못함 | 화면 문구 파일을 읽지 못해 마지막으로 정상이던 글자로 보입니다. |
| 지도를 불러오지 못함 | 지도를 불러오지 못했습니다. 인터넷 연결을 확인해 주세요. 문의 목록과 답변 초안은 그대로 쓸 수 있습니다. |

> [!note] 「엔진 기록 없이 연결됨」은 엔진 주소가 채점 서버(`/ask` 네 칸만 줌)일 때다. 그때는 판정 낱말이 없고, 원문 구절 대신 인용한 조항의 원문을 조례 원문 자료(`engine/data/chunks_paragraph.json`)에서 찾아 보인다.
