## 문제
- 영역: 엔진 (색인)
- 위치: `engine/build_index.py`(조각 만들기), 검색 결과 겹침 지우기는 `engine/retrieve.py`
- 왜: 검색이 놓치는 이유 가운데 조각 글 자체의 문제가 있다(11/6 키 없이 잼, plan 1-3절)
  - 「조는 맞고 항이 다름」 51문항(절반 점수). 주차장 제7조 제1항처럼 호가 18개인 긴 항은 조각 하나에 여러 주제가 섞인다
  - 항이 없는 조 조각 58개는 모두 머리말(「[조례 이름 제N조(제목)]」)이 없다. 임베딩에 조례 이름이 안 들어가 킷 예시 S3(청년 나이)가 엉뚱한 조항으로 간 원인으로 본다
  - 조문 끝 꼬리표(「<개정 …>」 · 「[본조신설 …]」 · 「…까지 유효함」 · 「종전 제28조는 …로 이동」)가 조각 글의 약 9%다(노트 18 B11). 검색 잡음이고, 「2019년 12월 31일까지 유효함」 같은 꼬리표는 답을 틀리게 만든다
  - 별표는 1,800자씩 잘라 넣는다. 표의 행이 잘리거나 머리글과 떨어진다. dev 정답에 별표가 든 문항은 59개다

## 재현
해당 없음 (실험)

## 작업 계약
- 선행 의존성: 00 엔진 뼈대 병합 뒤 (점수는 01 점수 틀로)

#### 할 일
- [ ] 꼬리표를 정규식으로 떼어 조각의 다른 칸에 보관한다. 꼬리표 밖 본문 글자는 그대로다
- [ ] 항이 없는 조 조각에도 항 조각과 같은 머리말을 붙인다
- [ ] 호가 여러 개인 긴 항은 호 단위 작은 조각을 더한다. 라벨은 항 그대로 두고, 검색 결과에서 같은 라벨은 하나로 합친다
- [ ] 별표는 표 행 단위 조각으로 만들고 행마다 머리글을 되풀이한다(라벨은 「별표 N」 그대로)
- [ ] 스위치 네 개(꼬리표 · 머리말 · 호 · 별표 행)를 따로 켜고 끌 수 있게 하고, 색인 판 이름을 판단 기록에 남긴다
- [ ] 키 없이 키워드 검색으로 스위치마다 dev 검색 적중률을 잰다. 좋아진 것만 켠 판으로 임베딩을 다시 만들어(조각 1,000개 안팎, 소액) 혼합 검색 적중률과 끝까지 점수를 잰다

#### 하지 않을 것 (이 이슈의 경계)
- 원칙 · 예외 · 참조 묶음 (08 몫)
- 질문 다듬기 (06 몫)
- 「…까지 유효함」 꼬리표가 지금도 효력이 있는지 판단하기. 떼어 보관만 하고 판단은 사람 확인으로 남긴다

#### 완료 조건
- [ ] dev 키워드 검색 적중률(top-6)이 70.0%보다 떨어지지 않고, 「조는 맞고 항이 다름」 문항 수가 51에서 얼마나 줄었는지 적었다
- [ ] 단위 시험: 뗀 뒤 조각에 꼬리표 0건, 꼬리표 밖 본문 글자 차이 0
- [ ] 켠 판과 끈 판의 dev 점수가 `experiments.md`에 있다 (키워드 적중률, 혼합 적중률, 끝까지 점수)
