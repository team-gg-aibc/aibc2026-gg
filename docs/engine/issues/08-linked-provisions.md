## 문제
- 영역: 엔진 (색인 + 검색 뒤)
- 위치: `engine/build_index.py`(연결표 만들기), `engine/retrieve.py`(검색 뒤 붙이기)
- 왜: 여러 조항 결합형이 가장 약하다. dev 결합 114문항의 키워드 top-6 적중률은 62%이고(단순 · 조건은 72%), 못 찾은 근거 104개 중 84개는 찾은 근거와 **다른 조**에 있다(11/6 키 없이 잼). 본문에서 다른 조 · 항을 부르는 조각이 528개 중 193개다. 킷 예시 M1(장애인 + 다둥이 할인)도 「감면율이 높은 하나만」(제7조 제3항)을 놓쳤다. 강사도 「결합형은 검색 결과 하나로는 부족하다」, 「2단계 검색」을 들었다(특강 1주차 1 · 3교시)
