# 엔진 리더보드

> `python3 eval/board.py`가 `eval/runs/`의 실행 요약 3개로 만든다. 손으로 고치지 않는다. 규칙: [재현 규칙](reproducibility.md) · 기록 표: [실험 기록](experiments.md)

## 끝까지 돌린 점수

같은 문항끼리만 견준다(묶음 · 표본 · 문항 지문이 같은 표). 숫자는 % 점수다. **가중** = (3 × 단순 + 3 × 조건 + 3 × 결합 + 2 × 함정) ÷ 11. **출발 판 대비** = 같은 표의 출발 판(baseline, 코드 지문이 같은 것이 있으면 그것, 없으면 가장 최근 것)과의 가중 차이. **흔들림** = 출발 판을 같은 설정으로 여러 번 돌린 가중 폭과 견준 것. 채택 기준(계획 5-2절)은 「폭의 2배 넘게 오름」.

아직 없음. 키를 넣고 `python3 eval/run.py --split dev`(출발 판)와 `python3 eval/run.py --sample 100 --repeat 3`(흔들림 폭)을 돌린 뒤 이 명령을 다시 돌린다.
