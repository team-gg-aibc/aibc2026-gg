## 끝까지 돌린 점수

같은 문항끼리만 견준다(묶음 · 표본 · 문항 지문이 같은 표). 숫자는 % 점수다. **가중** = (3 × 단순 + 3 × 조건 + 3 × 결합 + 2 × 함정) ÷ 11. **출발 판 대비** = 같은 표의 출발 판(baseline, 코드 지문이 같은 것이 있으면 그것, 없으면 가장 최근 것)과의 가중 차이. **흔들림** = 출발 판을 같은 설정으로 여러 번 돌린 가중 폭과 견준 것. 채택 기준(계획 5-2절)은 「폭의 2배 넘게 오름」. **(탐색)** = 90초 조건 없이 잰 실행(1~3주기). **궤적** = 문항마다 단계별 입력 · 프롬프트 · 모델 출력을 보는 화면으로, 그 실행을 돌린 컴퓨터에만 있다(`eval/results/`는 git에 안 올림). **비교** = 기준과 문항마다 견준 문서(`eval/compare.py`)로, 커밋돼 있어 GitHub에서 열린다.

**재는 법 기본값**: 채택 판단은 **dev 전체**로 하고, 켠 판 · 끈 판을 **각각 두 번 이상** 잰다(`python3 eval/run.py --config <설정> --split dev --repeat 2`). 100문항 표본은 빠른 확인용으로만 쓴다(흔들림이 2.5~4.9점이라 채택 판단에 쓰지 않는다). dev 전체 한 판은 약 10분, 기록 비용 약 $0.38이다. 실제 콘솔 차감은 그 6할쯤이라 한 판 약 $0.2다(11-06 기준).

**가설 나무**(가설 → 실험 → 다음 가설): 로컬에서 보기 `open docs/engine/tree.html`(배분일에 `python3 eval/board.py --tree`로 다시 만든다).
