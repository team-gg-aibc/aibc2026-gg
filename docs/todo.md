# 할 일

PM(동규)이 정한 사람별 할 일이다. GG비서가 매일 아침 8시에 각자 개인 채널로 보내고, 새로 생긴 일은 15분 안에 알려 준다.

- 마감이 있으면 `(마감 10/27)`처럼 적는다.
- 끝난 일은 개인 채널에서 「했어」를 누르면 비서가 `[x]`로 바꾼다. 할 일을 더하거나 고치는 건 PM이 PR로 한다.
- 같이 해야 하는 일은 함께 할 사람 칸에 모두 적고, 할 일 옆에 `(동욱이랑 협업해서 진행 필요)`처럼 같이 할 사람을 적는다. 이 이름은 디스코드에서 부르지(멘션) 않는다.
- 출처: 1차 회의(10/21). 노션 대신 디스코드를 쓰기로 해서(10/22) 노션에 관한 일은 디스코드로 바꿔 적었다.
- 10/26: 10/24 업스테이지 특강 내용으로 고쳤다(대상이 서울시 조례 6종으로 정해짐, 크레딧은 각자 신청). 자세한 건 `docs/education/2026-10-24-업스테이지-특강.md`.
- 10/28: 2차 회의(10/27) 결과를 반영했다. 2차 PRD는 한강 아이디어 하나를 각자 다듬어 10/31 회의 전까지 쓰고, 운영진 질문 · 서버 · 사업단 문의를 더했다. GitHub 조직 초대는 네 명 모두 수락한 것을 확인해 체크했고, 회의에서 발표한 아이디어 PRD + 목업도 체크했다. 평가셋 검수 분담은 동규가 평가셋을 본 뒤 따로 더한다.
- 10/26: 자동 리뷰 봇(Codex) 설정과 비용 확인은 동규가 직접 하고 있어서, 동규의 「자동 리뷰 절차 · 기준을 리뷰 봇 담당에게 넘기기」와 건영의 「자동 리뷰 봇 점검 후 필요한 것 · 비용 안내」를 뺐다.
