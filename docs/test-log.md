### 엔진 답이 흔들리는지 (같은 문의를 여러 번, 새 흐름 7판, 11-11 14시대)

넣어 본 횟수 = 미리 넣어 보기 4번 + 미리 받은 답 저장 1번. 화면 점검 때 첫 장면 문의를 다섯 번 더 넣었고(기록 길이 있는 엔진 3번 · `/ask`만 주는 엔진 2번) 다섯 번 다 초안이 나왔다(합치면 10번 중 9번).

| 문의 | 넣은 횟수 | 결과 |
|---|---|---|
| 첫 장면 대본(R02 선결제 환불) | 5 | 답함 4(인용 제13조 제2항 + 제3항, 4번 같음) · 「판정 거절」로 확인 불가 1 |
| R05 운영 종료 선결제 | 5 | 답함 5(인용 제13조 제2항 4번, 제2항 + 제1항 1번) |
| V038 남산공원 통행료 | 5 | 답함 5(별표 2, 같음) |
| V051 키즈카페 앞 흡연 | 5 | 답함 5(모두 금연 조례 제5조, 붙는 항 묶음은 셋으로 갈림: 제1 · 3 · 4항 2번, 제1 · 4항 2번, 제1 · 3항 1번) |
| V005 · V043 · V011 · V025 | 5씩 | 5번 다 같은 인용 |
| V034 어린이공원 정자 음주 | 4 | 답함 3 · 판정 거절 1 → 재생에서 뺌 |
| 6종 밖 문의(V063 · V071 · R29) | 5씩 | 5번 다 확인 불가(「found 거짓」 → 「조항을 찾지 못함」) |

- 6종 밖으로 넣어 본 실제 · 가상 문의 13건은 모두 「조항을 찾지 못함」 쪽(「found 거짓」 12 · 「판정 거절」 1)으로 갔고 「6종 밖」 갈래로 간 것은 0건이다. 한강공원 금지행위(R26)는 도시공원 조례로 답했다(알려진 약점).
- 미리 받은 답(`data/saved.json`)의 답 글 11건을 모두 읽었다: 묻지 않은 과태료 금액이 든 답은 없다.

### 두 번째 점검 (같은 날, 만든 쪽과 따로 다시 눌러 봄)

창을 띄우지 않는 headless 크롬(1440×900 · 1120 · 1200 · 1280 · 휴대폰 390×844)으로, 핵심 흐름을 엔진 실제 호출과 미리 받은 답 방식에서 한 번씩 다시 누르고(26/26 · 26/26), 사람이 할 법한 엇나간 길 13묶음을 보았다. 늦는 엔진 · 죽는 엔진 · 깨진 답은 업스테이지를 부르지 않는 가짜 엔진으로 흉내 냈다.

| 찾은 것 | 어떻게 다시 만드나 | 고친 뒤 |
|---|---|---|
| 승인 확인 창에 「처음 상태로 되돌립니다」 글과 버튼이 뜬다(누르면 실제로는 승인되어 시민에게 나감) | 「처음 상태로 되돌리기」 → 「그만두기」 → 아무 카드에서 「승인 완료」 고르기 | 통과: 창을 열 때마다 글을 놓는다 |
| 시민 화면이 「접수됨」에서 나갈 수 없다 | 조항을 붙이지 못한 문의를 시민 화면에서 보냄(담당자가 답을 보낼 길이 없어 답이 오지 않는다) | 통과: 「접수됨」에도 「새 문의 쓰기」 |
| 1.2초마다 목록 · 카드를 통째로 다시 그려 누름 · 고른 글 · 글쇠 초점이 사라진다 | 목록 줄을 1.5초 누르고 있다 떼기, 카드의 원문 구절을 마우스로 골라 2~3초 두기 | 통과: 값이 바뀐 때만 다시 그린다 |
| 처음 지도에서 문의 점이 시민 화면 · 목록 밑에 숨는다(1440×900에서 장소가 붙은 시연 문의 3개 중 1개만 보임) | 시연 문의를 들여온 뒤 지도 보기 | 통과: 칸에 가리지 않는 곳을 가운데로 |
| 휴대폰 · 좁은 화면에서 문의를 눌러도 바뀐 것이 안 보인다(카드가 목록 아래 화면 밖에 열림) | 390px에서 목록 줄 누르기 | 통과: 카드 자리로 내려간다 |
| 1100~1199px에서 카드가 문의 목록을 58px 덮는다 | 창 너비 1120px에서 카드 열기 | 통과: 탭 꼴로 바뀌는 기준을 1199px로 |
| 엔진이 도중에 꺼져도 위쪽이 계속 「엔진 연결됨」 | 엔진을 켜고 문의 하나 → 엔진을 끄고 12초 뒤 | 통과: 10초 안에 「연결되지 않음」 |
| 미리 받은 답 방식에서 처음 보는 문의의 카드가 「연결이 끊긴 경우입니다」라고 하고, 눌러도 소용없는 「다시 시도」가 있다 | `DESK_ENGINE=saved`로 띄워 예시가 아닌 문의 보내기 | 통과: 「미리 받아 둔 답으로만 보이는 방식이라 보일 답이 없습니다」, 버튼 없음 |
| 서버가 이상한 요청 본문(JSON 배열 · 숫자가 아닌 길이 · 목록으로 온 장소)에 답 없이 연결을 끊는다 | `POST /api/inquiries`에 `[1,2,3]` | 통과: 400으로 답한다 |
| 1,000자 문의가 목록 한 줄을 1,007px로 늘린다 | 긴 문의 보내기 | 통과: 목록에서는 세 줄까지 |
| 다 들여온 뒤 막힌 「시연 문의 들여오기」에 까닭이 없다 | 10건을 다 들여온 뒤 | 통과: 「시연 문의를 모두 들여왔습니다.」 |
| 답 네 칸만 주는 엔진을 한 번 만나면, 기록 길이 있는 엔진으로 바꿔 띄워도 화면 서버를 다시 띄울 때까지 「답 네 칸만」으로 남는다 | 엔진을 `/ask`만 주는 것 → 기록 길이 있는 것으로 바꿔 띄우고 문의 보내기 | 통과: 문의마다 기록 길부터 불러 본다 |

- 문제없던 것: 빈 문의 · 빈칸만 쓴 문의(안내, 서버 400), 보내기 두 번 누르기(한 번만 들어감), 같은 글 두 번(번호가 따로 붙음), 꺾쇠 · 따옴표가 든 문의와 답(글자 그대로 보이고 실행되지 않음), 웹 폴더 밖 파일 달라는 주소 여덟 가지(모두 404), 승인 뒤 다시 고치기 · 다시 승인(서버 409), 같은 때에 두 사람이 승인(하나만 받아들여짐), 늦는 엔진(「초안 작성 중」인 동안 다른 문의가 눌림), 기다림을 넘긴 엔진 · 오류 · 깨진 답(「불러오지 못함」 → 다시 시도로 살아남), 들여오는 중 되돌리기, 새로고침 · 뒤로 갔다 오기(목록과 시민 화면이 그대로), 콘솔 오류 없음.
- 고치지 않고 남긴 것: 고쳐 쓰다 칸을 떠나지 않고 새로고침하면 고치던 글이 사라진다. 새로고침하면 열어 둔 카드가 닫힌다. 두 창에서 한쪽이 승인하면 다른 쪽이 쓰던 글이 알림 없이 사라진다. 시연 10건에는 「6종 밖」 카드가 없다(엔진이 그렇게 가르는 것은 자치구 조례를 이름으로 든 문의뿐). 「승인 전」과 「근거 조항 없음」을 함께 고르면 늘 0건이다. 휴대폰에서 부서 칩 높이 36px. 화면 서버에는 로그인이 없어 주소를 밖에 열면 누구나 「처음 상태로 되돌리기」를 부를 수 있다(로컬 시연에서는 문제없음).
