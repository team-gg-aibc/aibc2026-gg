# 인터뷰 기록지 (한 사람에 한 장)

> 인터뷰가 끝난 **그날** 채운다. 두 사람이 같은 꼴로 적어야 견줄 수 있다. 한 칸에는 들은 말과 내 해석을 섞지 않는다: 들은 말은 「따옴표」로, 내 해석은 맨 아래 「적은 사람 메모」 칸에만 `[짐작]`을 붙여 적는다.
> 이름 · 연락처 · 직급 · 기관 이름 · 민원인 정보(이름 · 차량번호 · 주소 · 접수번호)는 어디에도 적지 않는다.

## 1. 한 장 기록지 (복사해서 쓴다)

```markdown
# 기록 [갈래 글자]-[두 자리 번호]   (예: 가-01, 대리-02)

## 머리
| 칸 | 적을 것 |
|---|---|
| 적은 사람 | 조사 1 / 조사 2 (이름 대신) |
| 날짜 · 걸린 시간 | 2026-11-__ · __분 |
| 방식 | 만남 / 전화 / 화상 |
| 갈래 | 가 시설 운영 기관 / 나 시 부서 / 다 구청 / 라 120 상담 / 마 시민 / 대리 |
| 기관 종류 (이름 X) | 예: 시설 운영 기관, 시 본청 부서, 자치구, 전화 상담, 학교 행정 부서 |
| 그 일을 한 기간 | 1년 미만 / 1~3년 / 3년 넘게 · 지금 하는 일 / 예전 일 |
| 서울시 일인가 | 예 / 아니오(대리) |
| 동의 | 녹음 ○ ✕ · 말 그대로 인용 ○ ✕ · 기관 종류를 발표에 적기 ○ ✕ · 녹음 지울 날 ____ |

## 6종 문의가 얼마나 오나 (A2 · B1)
- 지난 한 주 문의, 열린 대답 그대로: 「                                  」
- 목록을 읽어 드린 뒤: 6종 주제 문의 __건쯤 / 전체 __건쯤 [자기 보고] · 주로 어느 주제: ____

## 다섯 가지
칸마다: 들은 말(따옴표, 한두 문장) / 스스로 꺼냄·물어서 나옴 / 개인 경험·공식 안내라고 함 / 어느 쪽

### ① 답에 근거를 적는지 · 왜 (A5 · A6 · B3 · C5)
- 가장 최근 답의 근거 표기: 조 번호까지 / 규정 이름만 / 「관련 규정」 / 없음 / 기억 안 남
- 그 까닭, 들은 말: 「                                  」
- 적는 답과 적지 않는 답을 가르는 기준, 들은 말: 「                                  」
- 작성 요령 · 점검이 있나: 있다 / 없다 / 모른다 · 공개된 것이면 이름: ____
- 어느 쪽: 문제 문장 앞 절반(P1)을 받침 / 흔들림 / 이 사람은 모름

### ② 무엇을 찾고 얼마나 걸렸나 (A3 · A4 · B2)
- 처음 연 것 순서: ________ → ________ → ________
  (조례 원문 / 지난 답 / 내부 매뉴얼 · 표준 문안 / 동료 / 검색 / 그 밖: ____)
- 그 한 건에 걸린 시간 [자기 보고]: 찾기 __분 · 쓰기 __분 · 넘기고 기다림 __ · 전체 __
- 가장 오래 걸린 곳, 들은 말: 「                                  」

### ③ 장소 때문에 답이 갈린 일 (A7 · A8 · A9 · B4~B6 · C8)
- 있다(스스로 꺼냄) / 있다(물어서 나옴) / 드물다 · 없다 / 모른다
- 예, 들은 말: 「                                  」
- 다른 곳 일이라 넘긴 문의: 한 주에 __건쯤 · 넘길 곳을 찾은 법: ____

### ④ 지금 쓰는 화면 (A10 · A11 · B7)
- 열어 두는 창 · 프로그램 수: __개 · 가장 자주 오가는 두 곳: ____ / ____
- 답을 쓰는 곳 안에서 찾기까지 되나: 된다 / 따로 찾는다 / 모른다
- 가장 최근 새 도구가 들어올 때 거친 것: 보안 심사 / 결재 / 교육 / 책임 정하기 / 그 밖 ____ (스스로 꺼냄 · 물어서 나옴)
- 막히거나 늦어진 곳, 들은 말: 「                                  」

### ⑤ 남이 쓴 글을 고쳐 쓰기 · 승인 (A12 · A13 · A14 · A15 · B8)
- 지난 답 · 표준 문안 · 동료 글을 가져다 고쳐 씀: 자주 / 가끔 / 안 함
- 내보내기 전에 누가 봄: 있다 / 없다 · 최근 고쳐진 곳: 결론 / 근거 / 말투 / 그 밖
- 남이 쓴 글 때문에 곤란했던 일과 그 까닭: 옛 규정 / 다른 시설 · 다른 구 / 없는 규정 / 말투 / 그 밖 · 들은 말: 「          」
- 새 검색 · AI 도구: 써 봄(지금도 씀 / 그만둠) / 안내만 받음 / 없음 · 쓰는 까닭 또는 그만둔 까닭: 「          」 · 결과물에서 마음에 걸린 곳: 「          」
- (화면을 보여 줬다면, 따로) 보고 처음 한 말 · 처음 본 곳 · 그대로 내보낸다면 마음에 걸리는 곳: 「          」

## 그 밖
- 가장 놀란 말 하나 (그대로): 「                                  」
- 처음 들은 현장 말(낱말과 뜻): ____
- 다음 사람에게 물어볼 것: ____
- 소개해 줄 수 있다고 한 갈래 (연락처 X): ____

## 적은 사람 메모 [짐작]
- (내 해석은 여기에만)

## 끝 점검
- [ ] 이름 · 연락처 · 직급 · 기관 이름 · 민원인 정보가 이 장에 없다
- [ ] 따옴표 안은 들은 말 그대로다(줄였으면 「…」로 표시)
- [ ] 「개인 경험」과 「공식 안내」를 나눠 적었다
```

## 2. 모음표 (매일 저녁, 한 사람당 한 줄)

두 사람이 같은 파일 하나에 줄을 더한다. 칸에는 기록지의 선택지 낱말만 쓰고, 긴 말은 기록지에 둔다.

| 번호 | 적은 사람 | 갈래 | 6종 문의 (한 주) | ① 근거 표기 | ① 까닭 (한 줄 요지) | ② 처음 연 것 | ② 그 한 건 시간 [자기 보고] | ③ 장소 | ④ 새 도구에 걸리는 것 | ⑤ 고쳐 씀 | ⑤ 승인 단계 | ⑤ 곤란했던 까닭 | ⑤ AI 도구 | 가장 놀란 말 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 가-01 | 조사 1 | 가 | | | | | | | | | | | | |

다 모이면 PM이 이 표로 `01-누구에게-물을지.md` 5절의 「3명 중 2명」을 센다. 담당자 갈래(가 · 나 · 다)와 대리는 따로 센다.
