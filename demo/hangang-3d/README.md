# 한강 3D 상황판 시연 화면

AIBC2026 팀 GG 「현장 상황판」의 시연 화면이다. 서울 구간 한강을 3D 웹 지도로 보고, 오른쪽 위 「예시」를 누르면 여의도 한강공원 불꽃축제 날 저녁 상황판으로 바뀐다. **들어온 일 102건과 판정 카드는 모두 시연용 가상 예시**다. 엔진이 낸 답이 아니고, 조례 조항 문장만 `eval/source/`의 시행본 원문에서 옮겼다.

## 띄우는 법

레포 맨 위에서 한 줄 실행한 뒤 크롬에서 http://127.0.0.1:8765 를 연다. 끝낼 때는 터미널에서 Ctrl+C.

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory demo/hangang-3d/web
```

- 지도 타일과 MapLibre를 인터넷(CDN)에서 받으므로 인터넷이 필요하다.
- 예시 장면부터 열기: http://127.0.0.1:8765/?scene=fireworks (뒤에 `&t=<재생 초 0~45>&card=<번호>`를 붙이면 그 시각 · 그 카드로)
- 주소 뒤 `#줌/위도/경도/방위/기울기`로 시점을 공유할 수 있다.

## 화면

| 화면 | 할 수 있는 것 |
|---|---|
| 낮 지도 (한강 3D 지도) | 끌어서 이동, 오른쪽 버튼(또는 Ctrl)으로 돌리기 · 기울이기, 휠로 확대. 「한강 전체」 · 「여의도 시연 장면」 · 「한강 따라 날기」(약 2분) · 「다리로 이동」. 왼쪽 「들어온 일 102건」 목록 |
| 예시 (현장 상황판) | 밤으로 바뀌고 강 위에서 불꽃이 터진다. 19:00~19:30에 들어온 일을 45초에 재생한다. 왼쪽 휴대폰은 1번 시민 신고를 보내고, 승인하면 현장 휴대폰에 안내가 도착한다. 「낮 화면으로」로 돌아간다 |

- 번호 = 들어온 순서(1번 = 19:02 시민 신고). 동그라미 색 = 맡은 부서(건강관리과 · 자전거PM과 · 동물보호과 · 주차계획과 · 정원도시정책과 · 청년정책담당관).
- 목록 위에서 「들어온 순서 · 부서별로 모아 보기」와 「전체 · 미해결 · 해결」을 고른다. 부서 칩을 누르면 그 부서 일만 남고, 지도 점도 같이 걸러진다.
- 해결 = 맡은 부서가 안내를 승인해 현장에 보낸 일이다. 재생 중에는 부서들이 차례로 승인한다(가상: 배경 일의 70%를 4~15분 뒤에 승인). 판정 카드에서 「안내 승인」을 누르면 직접 해결할 수 있다.

## 파일

| 경로 | 내용 |
|---|---|
| `web/index.html` · `app.js` · `style.css` · `fireworks.js` | 화면 (MapLibre GL JS 5.6.0 + OpenFreeMap 3D 건물, 키 없음) |
| `web/data/*.geojson` | OSM에서 뽑은 한강 다리 판 · 교각 · 이름표, 한강공원 면, 1번 자리 10m 범위, 핵심 7건 자리 |
| `web/data/complaints.json` | 들어온 일 102건(가상)과 판정 카드 틀 20개 |
| `web/data/text.json` | 화면 글자 전부. `docs/content/`에서 `build_text.py`가 만든 결과라 손으로 고치지 않는다 |
| `scripts/prep_web.py` | OSM 원본 → `web/data/*.geojson` |
| `scripts/build_text.py` · `content.py` | `docs/content/*.md`를 읽어 `web/data/text.json`을 만든다 |
| `scripts/make_complaints.py` · `background.py` | 들어온 일 102건 만들기(같은 입력이면 같은 결과). 카드 문장 · 부서 이름 · 전화 · 핵심 7건은 `docs/content/`에서 읽는다 |

스크립트가 읽는 OSM 원본(`data/`, 약 13MB)은 이 레포에 넣지 않았다. `make_complaints.py`를 다시 돌릴 일이 있으면 PM에게 받아 `HANGANG_DATA=<그 data 폴더> python3 -I demo/hangang-3d/scripts/make_complaints.py`로 돌린다. 화면은 `web/`만으로 그대로 뜬다.

## 알아 둘 것

- **화면 문구의 원본은 `docs/content/`다**(A-01 현장 상황판 · A-04 한강 3D 지도 · U-01 현장 휴대폰 · U-02 시민 신고 · C-01 판정 카드 예시). 화면은 글자를 `web/data/text.json`에서만 읽는다. 문구를 고치면 레포 맨 위에서 `python3 -I demo/hangang-3d/scripts/build_text.py`를 돌린다. 카드 문장이나 핵심 7건을 고쳤으면 `make_complaints.py`도 다시 돌린다.
- 조례가 「지정할 수 있다」 · 「할인할 수 있다」고만 정한 곳은 판정을 「확인 필요」로 둔다.
- 다리 높이와 교각 자리는 규칙으로 놓은 근사값이다(실제 위치가 아니다).
- 잠실 · 강서한강공원은 OSM에 이름 붙은 공원 면이 없어 초록 면과 이름표가 없다.
- 로컬 `http.server`는 여러 파일을 한꺼번에 받다가 연결을 끊을 때가 있어서, 화면이 실패한 파일을 한 번 더 받는다.
